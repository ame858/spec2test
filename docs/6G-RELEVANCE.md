# 6G 相关性一页：6G 冻结后迁移什么

> 口径：6G 尚未标准化。项目基线采用“首个 6G 规范冻结约 2028-12”的公开时间表；本作品当前只在 **NR Rel-19（5G-Advanced）** 上验证，不宣称 6G 已实现。本文回答评委最关心的问题：**6G 规范冻结后，这套东西到底迁移什么？**

## 一句话

迁移的不是现在的 8 个用例，而是**“规范条款 → 可执行测试意图 → 确定性校验 → 字段级证据”这条方法与流水线**。6G 的测试规范仍然由条款、步骤、消息和 IE 组成；只要新规范能抽出符号表，同一条流水线就能跑。

## 三个具体迁移对象

| 6G 方向 | 3GPP 里的当前对应物 | 本作品已有的同构物 | 6G 冻结后要补的 |
|---|---|---|---|
| **NTN 测试** | TS 38.523-1 §6.7 NR NTN 空闲态小区选择/重选（当前 8 例） | 条款解析 → IR → 步骤/消息/IE → R1/R2/R3 → 逐例证据 | 新 release 的 38.523/38.331 符号表；6G NTN 新流程（再生载荷、星间链路、移动性）的用例切片 |
| **AI 空口测试** | Rel-18 AI/ML for NR 研究（TR 38.843）、Rel-19 CSI/波束/定位的 AI/ML 规范化推进 | “测试目的 → 测试意图”的表达层；IE/字段/步骤覆盖的确定性校验 | AI/ML 生命周期（数据收集、模型管理、监控）的测试意图模板；模型性能本身不在本工具范围，需与仿真/OTA 测试台分工 |
| **网络自动化测试** | NWDAF（TS 23.288）、节能/移动性优化等网络自动化用例 | 条款 → 意图 → 校验 → 证据的通用骨架；R3 的“测试目的必须被步骤覆盖”可直接复用 | 非 ASN.1 的符号表适配器（HTTP/JSON schema、策略模型）；TS 28/38 系列测试规范的解析器 |

## 为什么不是“蹭赛道”

1. **当前验证的是 5G-Advanced，不是 6G。** 8 个用例全部来自 NR Rel-19 的 TS 38.523-1；页面、文档、答辩口径都写明“6G 未标准化、在 Rel-19 上验证”。
2. **迁移的是可复用的工程物，不是口号。** 符号表是 release 参数化的：换 release 就重建符号表；校验规则 R1/R2/R3 不依赖具体用例；IR 与证据链不绑定 NTN。6G 规范一旦可解析，增量工作是“新符号表 + 新用例切片 + 新适配器”，不是重写产品。
3. **边界写清楚。** AI 空口的模型性能、6G 新空口的射频指标，不由本工具判定；本工具只判定“测试意图的结构、字段、步骤覆盖是否与规范一致”。这条边界避免把“测试意图编译器”说成“6G 全栈验证平台”。

## 第二域：AI 管理域

迁移实验选定的第二域是 AI 管理域，条款来源为 **TS 28.105 §6.2c.2（消费者请求测试）与 §7 信息模型（`MLTestingFunction` / `MLTestingRequest` / `MLTestingReport`）**。TS 23.288 提供 AI 网元的实体身份与服务骨架，TR 38.843 §7.3 作为 AI/ML 可测性的官方框架锚点。

**判据降级**：第一域的判据来源是官方测试条款（条款级）。TS 28.105 是管理规范，没有测试用例条款，第二域的判据降为「规范过程 + 信息模型约束」——只判步骤是否覆盖过程分支、服务操作与参数是否存在于规范、信息模型字段是否合法，不判定取值。降级量按 ADR-0009 量化并写入迁移报告。

## 6G 冻结后的 90 天迁移路线（可写进方案）

| 阶段 | 动作 | 产出 | 判据 |
|---|---|---|---|
| 第 1–2 周 | 从首个 6G 测试规范抽取条款与 ASN.1/IDL 符号表 | 6G 符号表 v0 | 至少 1 个消息/IE 表可解析 |
| 第 3–6 周 | 选 1 个 6G NTN 或 AI 空口用例做穿 | 1 个端到端用例 | 生成 → R1/R2/R3 → 证据 → 导出 |
| 第 7–10 周 | 加非 ASN.1 适配器（网络自动化 JSON schema） | 第二个规范切片 | 同一套校验/评分/证据链 |
| 第 11–13 周 | 与测试团队做小规模评审 | 评审记录 + 缺陷清单 | 至少 1 名测试工程师确认字段级证据可用 |

## 与 ADR 的一致性

- **ADR-0001（诚实框架）**：明确 6G 未标准化，不用“6G 已实现”换分。
- **ADR-0002（遮住答案做评测）**：6G 迁移后仍按同一盲评协议，不拿未来答案驱动生成。
- **ADR-0006（可验证性优先）**：6G 用例同样先过确定性校验器，不合格拒收、信息不足弃权。
- **ADR-0008（第二域只作迁移证明）**：第二域只做 1–2 条条款，不转主场景。
- **ADR-0009（判据来源降级）**：第二域判据从条款级降为过程级，降级量必须量化。

## 评委可复述的三句话

1. 现在验的是 Rel-19，不是 6G；6G 还没冻结。
2. 6G 冻结后迁移的是“规范即 oracle”的流水线，不是这 8 个用例。
3. NTN、AI 空口、网络自动化三个方向都能接，但 AI 模型性能和射频指标不归这个工具判。
