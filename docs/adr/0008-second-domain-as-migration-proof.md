# 第二域只作迁移证明，不转主场景

为加深 AI 与 6G 结合，新增 AI 管理域（以 TS 28.105 为条款来源）。决定：第二域只做 1–2 条条款，用来证明"同一套六阶段骨架换域可跑"；产品主场景仍是无线域加规范升级回归；NTN 的 8 个用例不降级为历史包袱。

**Why:** NTN 8 例是唯一同时具备官方答案与实测数字的资产（L1 8/8、缺陷 31/31、真实错误 16/19）。把第二域做成主场景等于扔掉唯一可信度资产，且需重建用户、场景与演示。
**How to apply:** 六阶段骨架不改，只加"域 profile"（提示词、词表、符号表路径按域切换）；不新增独立流水线；第二域验收标准是"跑通 + 报数字"，不设分数阈值。

## Consequences

第二域覆盖面刻意窄。若被问"ML 域能测多少"，答案固定为"1–2 条，用于证明换域"，不扩口。
