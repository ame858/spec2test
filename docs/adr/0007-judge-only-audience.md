# 受众只有评委，网页不展示受众

`PRODUCT.md` 曾列三个次要受众（协议测试工程师、评测/审阅者、研究者与学生），但一个都未验证。本作品唯一的实际读者是评委。决定：对外受众只写评委；网页端不展示任何"受众是谁"的表述；"应用前景"改写为"能力可迁移到哪些场景"，不点名角色。

**Why:** 虚构用户会撞 ADR-0001 的诚实原则。评委不是用户而是观众，把观众写成用户会让"应用前景"变成自说自话；而在网页上写"我们的用户是评委"，对评委本身是减分项。
**How to apply:** `PRODUCT.md`、`NARRATIVE.md` 的受众段只保留评委；应用前景用"能力可迁移"表述；`webapp/` 不新增受众说明，`AboutView` 现有"没有用户研究"一句保留。

## Consequences

"应用前景"与"落地可行性"两项失去"真实用户"论证，只能靠外部背书补。`docs/REDTEAM.md` 已指出外部背书是这两项的唯一翻盘点。
