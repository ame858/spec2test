# 判据来源从条款级降为过程级

第一域 TS 38.523-1 有逐条可执行的一致性测试条款，官方规范即标准答案。第二域 TS 28.105 是管理规范，没有测试用例条款。决定：第二域的判据来源降为"规范过程 + 信息模型约束"——校验步骤是否覆盖规范过程分支、服务操作与参数是否存在于规范、信息模型字段是否合法；不判定取值。

**Why:** 3GPP 无 SBA/NWDAF 一致性测试规范（核心网测试体系在 ETSI TC INT，且未查到 NWDAF 专用套件）。若不降级，第二域无判据可用。
**How to apply:** 报告必须量化降级——主指标为"判定覆盖率 × 人工复核一致率"，辅以 R1/R2/R3 通过率与符号表建设工时；任何对外材料不得把第二域的"通过"表述成"符合规范"。

## Consequences

第一域与第二域的"通过"含义不同，必须分开表述。这条差异本身是迁移报告的交付物之一，不是需要掩盖的缺陷。
