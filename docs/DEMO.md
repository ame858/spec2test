# 演示脚本（6.5 分钟）

面向评委的固定路线。每步都写清“点什么、说什么、应该看到什么”。
模型通道不可用时走快速模式（不调用模型），讲解内容不变。

## 0. 开场（30 秒）

> 3GPP 测试条款是给人读的：步骤和 ASN.1 字段散在正文里。我们把它编译成机器可校验的测试意图，
> 再由确定性规则判对错。模型负责生成和修复，规则负责判定——这是可验证智能体的前提。

## 1. 数据与评测：先看结果（60 秒）

1. 点顶栏「数据与评测」。初始为空，只有一句“还没有运行结果”。
2. 点右上「一键测试全部用例」（默认勾选“快速模式”，不调用模型）。
3. 说：“8 个用例逐个跑，判定、L1、L3、违规数逐例列出，不报平均数。”
4. 指出 6.7.1.4 一行是「弃权」：输入里没有可识别消息名，不调用模型、不计分，也不会写成通过。

### 1b. 切域：同一套机器，两个域（30 秒）

1. 点右上角「RRC 域 | ML 域」分段胶囊，切到「ML 域」。
2. 用例列表从 8 例变成 1 例 `ml.1`（AI/ML 管理 / ML 模型测试）。
3. 点「一键测试全部用例」（快速模式），看到 L1=1.000、0 违规。
4. 说：“同一套六阶段、同一套校验器，换的只是符号表与提示词。第二域的判据比第一域弱——
   没有官方测试用例，只判过程与信息模型；降级量写在迁移报告里。”
5. 打开 `ml.1` 的拆解，指出步骤与字段都能回指 TS 28.105 的 IOC 与属性。
6. 切回「RRC 域」，列表恢复 8 例。

详细数字与失败模式见 `docs/MIGRATION-REPORT.md`。

## 2. 对话：一条真实链路（90 秒）

1. 回「对话」，输入 `运行用例 6.7.1.3`。
2. 回答下方出现运行卡片：判定点、L1、L3、违规数，右下「查看拆解 →」。
3. 点「trace」（卡片右上），右侧面板显示工具调用与运行日志。
4. 说：“每一步都有记录，判定不是模型写的，是校验器给的。”

## 3. 「+」菜单：把工程参数交给人（60 秒）

1. 点输入框左侧「+」。展示三组参数：生成范围、修复轮数、校验严格度。
2. 选「只生成步骤」和「跳过字段校验（R2）」，输入框上方出现对应 chip。
3. 展开「技能」：勾选 `sib19-required-fields`，出现技能 chip；
   说明：“技能是过程说明，选中后随本次修复提示带入，不是把规则塞进提示词。”
4. 展开「连接器 · 只读工具」：演示全不选/全选；说明未勾选的工具不会被助手调用。
5. 切到「编排方式 · 模型自选」，说明这一步由模型自己决定调用哪些工具、按什么顺序；
   跑一个用例后展开 trace：工具调用序列就是模型的决策轨迹，判定仍由校验器给出。

## 4. HITL：模型调用前的人工闸门（60 秒）

1. 说 `用人工审批运行 6.7.1.10`（或让助手以 hitl 方式运行）。
2. 审批卡出现：候选消息可多选，下方是本次参数摘要（范围 / 修复轮数 / 严格度）。
3. 取消勾选一个消息再批准：只说“只生成这些”，不要提前说结果。
4. 展示运行日志里的审批事件；说：“未批准或超时都不会调用模型，判定是取消。”

## 5. 证据链与修复（60 秒）

1. 点任一用例的「拆解 →」（或对话卡片的「查看拆解」）：右侧浮窗打开用例面板，不离开当前页；
   点遮罩或右上角 × 关闭。面板里是字段级证据、每条 TP 被哪个步骤引用、违规位置可回指。
2. 回「关于」，展示结构图与三条创新点。
3. 说：“修复增益与编排消融可以在本地复现，命令在复现一节；结果随仓库保存，逐例列出。”

## 6. 收尾（30 秒）

> 这套东西的可信度不来自模型说得好，而来自：规则能拒收、修复可对照、弃权有记录。
> 换 release 或换到 6G，增量是符号表、用例切片和适配器，不是重写。

## 评委常问

**“这不就是脚本吗？”**
固定管线是对照组。同一批工具交给模型自选顺序，两组放在同一张表里比调用数、耗时、判定；
消融命令 `py -3.12 scripts/ab_orchestration.py`。

**“31/31 是不是自测模板？”**
缺陷注入是自建受控样本，另有真实模型输出的人工标注集盲测（范围内 16/16），
以及官方答案 0/8 误报。三组数字口径不同，页面上分开写。

**“模型说对就算对吗？”**
不是。模型只提出与修复，通过与否由 R1/R2/R3 判；校验器自身异常按 R0 拒收。

**“为什么现在讲 6G？”**
6G 尚未标准化。可迁移的是工程物：符号表按 release 参数化，IR 与规则不绑定 NTN。

## 兜底

- 模型通道不可用：全程用“快速模式”，讲结构与证据，不演示生成。
- 服务未启动：仓库根目录 `start.bat`（Windows），或分别启动
  `py -3.12 scripts/serve.py --no-browser` 与 `cd webapp && npm run start`。
- 页面打不开：先看 `http://127.0.0.1:8000/api/health`，再刷页面。
